# DevVault

AI-powered knowledge and documentation management platform.

## Purpose

DevVault allows users to upload, organize, search and
interact with their documents using Retrieval-Augmented
Generation (RAG).

## Technology Stack

### Frontend
- Next.js
- TypeScript
- Tailwind CSS

### Backend
- Python
- Django
- Django REST Framework

### Database
- PostgreSQL
- pgvector

### AI
- Sentence Transformers
- LLM API
- Custom RAG pipeline

## Core Features

- User registration and authentication
- Workspace management
- Document uploads
- Document processing
- Semantic search
- AI-powered document conversations
- Source citations
- Role-based access control
